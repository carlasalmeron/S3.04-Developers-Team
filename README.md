# Agile Development Project - User Story Driven Application

**Description**: This project is a collaborative software development exercise focused on Agile methodologies. The application evolves through the continuous implementation of User Stories, prioritizing clean code, design patterns, and an organized Git workflow.

## 📌 Project Statement
Unlike traditional projects with fixed requirements, this development is guided exclusively by **User Stories**. Each feature is defined from the end-user's perspective to fulfill a specific goal and provide business value.

The success of this project relies on team collaboration, adaptability, and the application of industry best practices (SOLID, Design Patterns, and Containerization).

## ✨ Key Features & Agile Workflow
- **User Story Driven**: All features follow the format: *"As a [role], I want [action], so that [benefit]."*
- **GitHub Projects Integration**: Drafts are converted into Issues and managed via a Kanban board.
- **Agile Ceremonies**: Implementation of Daily Meetings to track progress and identify blockers.
- **Epic Management**: Large features are broken down into smaller, manageable stories for iterative development.

## 🛠 Technologies & Requirements
- **Backend**: Java (using `Records` for DTOs and `Optional` for null-safety).
- **Database**: MySQL / MongoDB (Deployed via **Docker**).
- **Architecture & Patterns**:
    - Repository Pattern for persistence.
    - At least 3 Design Patterns (e.g., Factory, Strategy, Singleton).
    - SOLID Principles compliance.
    - Feature-based project structure.
    - DTOs for inter-layer communication.
- **Testing**: Unit/Integration tests for core functionalities.
